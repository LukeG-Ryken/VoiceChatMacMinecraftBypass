# VoiceChatMacMinecraft
  This is a command that allows the mod Simple Voice Chat to work on Mac devices with the native Minecraft Launcher.
    If you do not have the Simple Voice Chat Mod, download it here:
  https://modrinth.com/plugin/simple-voice-chat
    Follow the steps in this documentation to install it:
  https://modrepo.de/minecraft/voicechat/wiki
    Then, click on the Minecraft.command file and find the download button. Download it to your mac.
